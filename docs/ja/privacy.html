プライバシーポリシー

スクスクお小遣い (FamilyBank)

ホーム サポート・お問い合わせ プライバシーポリシー

施行日：2026年7月16日 · 最終改定日：2026年10月16日

スクスクお小遣い（以下「本アプリ」）は、利用者の個人情報を大切に考え、 取り扱う個人情報を必要最小限にとどめるよう設計されています。本ポリシーは、本アプリがどのような 情報をどのように取り扱うかをわかりやすくご説明するものです。

概要 — 本アプリに会員登録はなく、利用者が入力した情報は 利用者のデバイスと利用者ご自身のiCloudアカウントの中だけに保存されます。 家族のメンバーや取引の記録といった入力情報が、開発者を含む第三者に送信・提供されることはなく、 広告やトラッキングのツールも使用していません。開発者に届くのは、保護者モードで保護者が ご自身で送信したご意見と、名前や入力内容を含まない匿名の利用統計・エラーレポートだけです。

1. 取得する情報

本アプリは、サービス提供のため、利用者がご自身で入力する次の情報をデバイスに保存します。

家族メンバーの情報メンバーの名前（またはニックネーム）と絵文字
保護者PIN保護者モードをロックするための4桁の数字（デバイス内にのみ保存）
お金の活動データ仮想通貨の残高、貯金額、投資の保有内容、ショップの項目
取引の記録お小遣い・支払い・貯金・投資などの取引内容とメモ、日付

上記はすべて利用者が任意に入力する値であり、本名・住所・電話番号・メールアドレス・決済カードなど、 実際の個人を特定する情報や金融情報の入力を求めることはありません。通貨と取引はすべて、 教育用の仮想データです。

2. 情報の保存場所

  • デバイス内への保存 — すべてのデータは、原則として利用者のデバイス内 （Apple SwiftData）に保存されます。
  • iCloud同期（任意） — 利用者がiCloudにサインインしている場合、家族のデバイス間で 同期するため、データは利用者ご自身のiCloudプライベートデータベース（Apple CloudKit Private Database）に保存・同期されます。このデータは利用者のAppleアカウントで 保護され、Appleのプライバシーポリシーに従って取り扱われます。
本アプリは、開発者が運営する独自のサーバーを持ちません。利用者が入力した データは利用者ご自身のiCloudにあるため、開発者がアクセスすることはできません。

3. 第三者提供および外部への送信

  • 本アプリは、利用者の情報を第三者に販売・提供・共有しません。
  • 広告SDK、外部の分析サービス、トラッキング技術を使用しません。
  • Apple iCloudによる同期と、下記の「ご意見の送信」「匿名の利用統計」以外に、データを外部へ送信することはありません。

ご意見の送信 — 保護者モードの「フィードバックを送る」から保護者がご自身で送信した場合にのみ送られます。 選んだ種類と書いた文章、アプリのバージョン・iOSのバージョン・デバイスの種類・デバイスの言語設定が開発者のApple CloudKitストレージに届きます。 お名前・メールアドレスは、返信を希望してご自身で入力した場合にのみ一緒に送られます。家族メンバーや取引の記録は含まれません。 お送りいただいたご意見は、返信とアプリの改善にのみ使用します。削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

匿名の利用統計 — 本アプリを利用している家族の数を把握し、不具合を修正するため、次の匿名統計を Apple iCloud（CloudKit）に送信します。閲覧できるのは開発者のみです。

  • インストール時に作成されるランダムなID（デバイス・Apple ID・他のアプリとは結びつかず、再インストールすると変わります）
  • アプリのバージョン、iOSのバージョン、地域・言語の設定
  • アプリを開いた回数と開いた日、インストール日とインストールからの経過日数
  • アプリがフリーズまたは異常終了した際の診断レポート（アプリのバージョン、iOSのバージョン、デバイスの種類、エラーの技術的な情報）

名前、連絡先、位置情報、家族メンバーや取引の記録などの入力内容は含みません。 iCloudにサインインしている場合にのみ送信されます。

4. 子どもの個人情報

本アプリは家族で一緒に使うことを前提としており、子どもも利用できます。本アプリは 子どもから本名や連絡先などの個人を特定する情報を取得せず、子どもに関する設定と データは、保護者の管理のもとでデバイス内に保存されます。本アプリが子どもの情報を 外部に送信したり、第三者に提供したりすることはありません。第3項の匿名の利用統計には、 誰がアプリを使っているかがわかる情報は含まれません。

本アプリは、米国の児童オンラインプライバシー保護法（COPPA）および大韓民国の個人情報保護法の 趣旨に沿って、子どもの個人情報を外部で取得しないよう設計されています。

5. デバイスの権限

本アプリは次の権限を求めることがありますが、いずれも任意です。

  • 通知 — 利息の精算など、アプリに関するお知らせに使われることがあり、 通知はデバイス内で処理されます。許可しなくても、アプリの主要な機能はご利用いただけます。
  • カメラ — バーコード決済機能を使う際に、バーコードを読み取るためだけに 使用し、撮影した画像が保存・送信されることはありません。
  • Face ID / Touch ID — 保護者の確認（保護者機能のロック解除）にのみ使用します。 認証はiOSがデバイス内で行い、本アプリが生体情報を受け取ったり保存したりすることはありません。

6. データの保存と削除

  • デバイスのデータ — アプリを削除すると、デバイスに保存されたデータも一緒に削除されます。
  • iCloudのデータ — iCloudに同期されたデータは、iOSの 設定 → Appleアカウント → iCloud → ストレージを管理から本アプリのデータを削除できます。
  • アプリの保護者モードで、メンバーや取引などのデータを個別に削除することもできます。

7. ポリシーの変更

本プライバシーポリシーは、法令やアプリの機能の変更に応じて改定されることがあります。重要な 変更がある場合は本ページでお知らせし、改定後のポリシーは掲載した時点から適用されます。
