🐣 スクスクお小遣いとは？

スクスクお小遣いは、家族の中だけで使う通貨を通して、子どもにお金と経済を 教えるiOSアプリです。親は中央銀行となってお小遣いを発行し、子どもは支払いをしたり、 貯金して利息を受け取ったり、模擬ファンドに投資したりしながら、経済のしくみを体験して学びます。

データはすべてお使いのデバイスとご自身のiCloudアカウントの中だけに保存されます。 会員登録は不要で、ご家族が入力した情報が開発者に送られることはありません。

✨ おもな機能

  • わが家の通貨 — 「マメ」「ホシ」「コイン」など、通貨の名前を自由に決められます
  • お小遣いの支給・差し引き — 保護者モード（PINで保護）で管理
  • 支払い — おやつやゲーム時間などを子どもが自分で支払い。バーコード決済にも対応
  • 貯金の利息 — 貯金口座に毎週、複利の利息が自動でつきます
  • 投資体験 — 安定型 🐢 ・ バランス型 🐰 ・ チャレンジ型 🚀 の模擬ファンド
  • 取引の記録 — お金の流れを日付ごとにふり返れます
  • お金の学び — 通貨・貯金・複利・投資・機会費用などをやさしく解説
