❓ Questions fréquentes

SukSuk Argent de poche utilise-t-il de l’argent réel ?

Non. La monnaie et les opérations de l’app sont entièrement fictives et pédagogiques. Elles ne sont liées à aucun compte bancaire, carte ou argent liquide : le but est d’aider l’enfant à découvrir les notions d’économie en toute sécurité.

Comment partager les données entre les appareils de la famille ?

Les appareils connectés au même compte iCloud se synchronisent automatiquement. Vérifiez qu’iCloud est activé dans Réglages → Compte Apple → iCloud. Sans iCloud, les données restent uniquement sur l’appareil concerné.

J’ai oublié le code PIN parent.

Par sécurité, le code PIN est stocké uniquement sur l’appareil : même le développeur ne peut pas le récupérer. En cas d’oubli, supprimez puis réinstallez l’app pour repartir de la configuration initiale. Attention : cela efface les données existantes.

Comment les intérêts de l’épargne sont-ils calculés ?

Les sommes placées sur le livret rapportent automatiquement des intérêts composés chaque semaine. Le taux se règle dans le mode parent, et les semaines en retard sont rattrapées automatiquement à l’ouverture de l’app.

Les cours des placements suivent-ils les vrais marchés ?

Non. Les cours des produits de placement sont des données fictives qui varient une fois par jour au sein de l’app, à des fins pédagogiques. Plus le produit est risqué, plus il fluctue. Il ne s’agit pas de vrais produits financiers.

Je veux supprimer toutes mes données.

Supprimer l’app efface les données enregistrées sur l’appareil. Pour les données synchronisées avec iCloud, supprimez les données de l’app dans Réglages → Compte Apple → iCloud → Gérer le stockage.

Quels appareils et versions d’iOS sont pris en charge ?

L’app fonctionne sur iPhone et iPad sous iOS 17.0 ou version ultérieure.

🔒 Confidentialité

Toutes les données de SukSuk Argent de poche restent sur l’appareil et dans votre propre compte iCloud. Le développeur reçoit seulement les avis envoyés volontairement depuis le mode parent, ainsi que des statistiques d’usage et rapports d’erreur anonymes.
