ซุกซุก ค่าขนม (FamilyBank)

หน้าแรก ช่วยเหลือและติดต่อ นโยบายความเป็นส่วนตัว

วันที่มีผลบังคับใช้: 16 กรกฎาคม 2569 · แก้ไขล่าสุด: 16 ตุลาคม 2569

ซุกซุก ค่าขนม (ต่อไปนี้เรียกว่า "แอป") ให้ความสำคัญกับข้อมูลส่วนบุคคลของผู้ใช้ และออกแบบมาให้จัดการข้อมูลส่วนบุคคลให้น้อยที่สุดเท่าที่จำเป็น นโยบายนี้จัดทำขึ้นเพื่อชี้แจงอย่างโปร่งใส ว่าแอปจัดการข้อมูลใดและด้วยวิธีใด

สรุปสาระสำคัญ — แอปไม่มีการสมัครสมาชิก และข้อมูลที่ผู้ใช้กรอกจะจัดเก็บ ไว้ในอุปกรณ์ของผู้ใช้และบัญชี iCloud ของผู้ใช้เองเท่านั้น ข้อมูลที่กรอก เช่น สมาชิกในครอบครัวและประวัติรายการ จะไม่ถูกส่งหรือเปิดเผยแก่บุคคลที่สาม รวมถึงผู้พัฒนา และแอปไม่ใช้เครื่องมือโฆษณาหรือการติดตามใดๆ สิ่งที่ส่งถึงผู้พัฒนามีเพียง ความคิดเห็นที่ผู้ปกครองส่งเองจากโหมดผู้ปกครอง และสถิติการใช้งานและรายงานข้อผิดพลาดแบบไม่ระบุตัวตนที่ไม่มีชื่อหรือเนื้อหาที่กรอกไว้

1. ข้อมูลที่เก็บรวบรวม

เพื่อให้บริการ แอปจะบันทึกข้อมูลต่อไปนี้ที่ผู้ใช้กรอกเองไว้ในอุปกรณ์

ข้อมูลสมาชิกในครอบครัวชื่อ (หรือชื่อเล่น) และอีโมจิของสมาชิก
PIN ผู้ปกครองตัวเลข 4 หลักสำหรับล็อกโหมดผู้ปกครอง (จัดเก็บในอุปกรณ์เท่านั้น)
ข้อมูลกิจกรรมทางเศรษฐกิจยอดเงินเสมือน ยอดเงินออม รายการลงทุนที่ถือ สินค้าในร้านค้า
ประวัติรายการรายการค่าขนม การจ่ายเงิน การออม การลงทุน พร้อมบันทึกและวันที่

ข้อมูลข้างต้นทั้งหมดเป็นค่าที่ผู้ใช้กรอกเองตามต้องการ แอปไม่ขอข้อมูลระบุตัวตนหรือข้อมูลทางการเงินจริง เช่น ชื่อจริง ที่อยู่ เบอร์โทรศัพท์ อีเมล หรือบัตรชำระเงิน สกุลเงินและรายการทั้งหมดเป็นข้อมูลสมมติ เพื่อการศึกษาเท่านั้น

2. สถานที่จัดเก็บข้อมูล

  • จัดเก็บในอุปกรณ์ — โดยค่าเริ่มต้น ข้อมูลทั้งหมดจะจัดเก็บไว้ภายในอุปกรณ์ของผู้ใช้ (Apple SwiftData)
  • ซิงค์ iCloud (ไม่บังคับ) — หากผู้ใช้ลงชื่อเข้า iCloud ไว้ ข้อมูลจะถูกจัดเก็บและซิงค์ใน ฐานข้อมูลส่วนตัว iCloud ของผู้ใช้เอง (Apple CloudKit Private Database) เพื่อให้อุปกรณ์ของครอบครัวตรงกัน ข้อมูลนี้ได้รับการปกป้องด้วยบัญชี Apple ของผู้ใช้ และจัดการตามนโยบายความเป็นส่วนตัวของ Apple
แอปไม่มีเซิร์ฟเวอร์แยกต่างหากที่ผู้พัฒนาดูแล ข้อมูลที่ผู้ใช้กรอกอยู่ใน iCloud ของผู้ใช้เอง ผู้พัฒนาจึงไม่สามารถเข้าถึงข้อมูลนั้นได้

3. การเปิดเผยแก่บุคคลที่สามและการส่งออกภายนอก

  • แอปไม่ขาย ให้ หรือแบ่งปันข้อมูลของผู้ใช้แก่บุคคลที่สาม
  • แอปไม่ใช้ SDK โฆษณา บริการวิเคราะห์ภายนอก หรือเทคโนโลยีการติดตาม
  • นอกจากการซิงค์ผ่าน Apple iCloud รวมถึง “การส่งความคิดเห็น” และ “สถิติการใช้งานแบบไม่ระบุตัวตน” ด้านล่าง แอปไม่ส่งข้อมูลออกไปภายนอกในทุกกรณี

การส่งความคิดเห็น — จะส่งก็ต่อเมื่อผู้ปกครองกดส่งเองผ่าน "ส่งความคิดเห็น" ในโหมดผู้ปกครองเท่านั้น ประเภทที่เลือก ข้อความที่เขียน เวอร์ชันแอป เวอร์ชัน iOS รุ่นอุปกรณ์ และภาษาที่ตั้งไว้ในอุปกรณ์ จะส่งไปยังพื้นที่จัดเก็บ Apple CloudKit ของผู้พัฒนา ส่วนชื่อและอีเมลจะส่งไปด้วยก็ต่อเมื่อคุณกรอกเองเพื่อรับคำตอบ โดยไม่รวมข้อมูลสมาชิกในครอบครัวและประวัติรายการ ความคิดเห็นที่ส่งมาใช้เพื่อตอบกลับและปรับปรุงแอปเท่านั้น หากต้องการให้ลบ โปรดแจ้งช่องทางติดต่อด้านล่าง

สถิติการใช้งานแบบไม่ระบุตัวตน — เพื่อให้รู้ว่ามีกี่ครอบครัวที่ใช้แอปและเพื่อแก้ไขข้อผิดพลาด แอปจะส่งสถิติแบบไม่ระบุตัวตนต่อไปนี้ไปยัง Apple iCloud (CloudKit) ซึ่งผู้พัฒนาเท่านั้นที่อ่านได้

  • ID แบบสุ่มที่สร้างขึ้นตอนติดตั้ง (ไม่เชื่อมโยงกับอุปกรณ์ Apple ID หรือแอปอื่น และจะเปลี่ยนเมื่อติดตั้งใหม่)
  • เวอร์ชันแอป เวอร์ชัน iOS การตั้งค่าภูมิภาคและภาษา
  • จำนวนครั้งและวันที่เปิดแอป วันที่ติดตั้ง และจำนวนวันนับจากติดตั้ง
  • รายงานการวินิจฉัยเมื่อแอปค้างหรือปิดตัวผิดปกติ (เวอร์ชันแอป เวอร์ชัน iOS รุ่นอุปกรณ์ ข้อมูลทางเทคนิคของข้อผิดพลาด)

ไม่รวมชื่อ ข้อมูลติดต่อ ตำแหน่ง หรือเนื้อหาที่กรอก เช่น สมาชิกในครอบครัวและประวัติรายการ และจะส่งเฉพาะเมื่อลงชื่อเข้า iCloud อยู่เท่านั้น

4. ข้อมูลส่วนบุคคลของเด็ก

แอปนี้ออกแบบมาเพื่อให้ครอบครัวใช้ร่วมกัน และเด็กสามารถใช้งานได้ แอปไม่เก็บข้อมูลระบุตัวตน เช่น ชื่อจริงหรือข้อมูลติดต่อจากเด็ก การตั้งค่าและข้อมูลที่เกี่ยวกับเด็กจะจัดเก็บในอุปกรณ์ภายใต้การดูแล ของพ่อแม่ (ผู้ปกครอง) แอปไม่ส่งข้อมูลของเด็กออกไปภายนอกหรือเปิดเผยแก่บุคคลที่สาม สถิติการใช้งานแบบไม่ระบุตัวตนในข้อ 3 ไม่มีข้อมูลที่บอกได้ว่าใครเป็นผู้ใช้แอป

แอปนี้ออกแบบตามเจตนารมณ์ของกฎหมายคุ้มครองความเป็นส่วนตัวออนไลน์ของเด็กของสหรัฐอเมริกา (COPPA) และกฎหมายคุ้มครองข้อมูลส่วนบุคคลของสาธารณรัฐเกาหลี (PIPA) เพื่อไม่ให้มีการเก็บข้อมูลส่วนบุคคลของเด็กออกไปภายนอก

5. สิทธิ์การเข้าถึงอุปกรณ์

แอปอาจขอสิทธิ์ต่อไปนี้ ซึ่งทั้งหมดเป็นตัวเลือกที่ไม่บังคับ

  • การแจ้งเตือน — อาจใช้เพื่อแจ้งข่าวที่เกี่ยวกับแอป เช่น การคำนวณดอกเบี้ย โดยการแจ้งเตือนจะประมวลผลภายในอุปกรณ์ แม้ไม่อนุญาตก็ยังใช้ฟีเจอร์หลักของแอปได้ตามปกติ
  • กล้อง — ใช้เพื่ออ่านบาร์โค้ดเมื่อใช้ฟีเจอร์จ่ายด้วยบาร์โค้ดเท่านั้น ภาพที่ถ่ายจะไม่ถูกบันทึกหรือส่งออกไป
  • Face ID / Touch ID — ใช้เพื่อยืนยันตัวผู้ปกครอง (ปลดล็อกฟีเจอร์ของผู้ปกครอง) เท่านั้น การยืนยันตัวตนดำเนินการโดย iOS ภายในอุปกรณ์ แอปไม่ได้รับหรือจัดเก็บข้อมูลชีวมิติ

6. การเก็บรักษาและการลบข้อมูล

  • ข้อมูลในอุปกรณ์ — เมื่อลบแอป ข้อมูลที่จัดเก็บในอุปกรณ์จะถูกลบไปด้วย
  • ข้อมูลใน iCloud — ข้อมูลที่ซิงค์กับ iCloud สามารถลบได้ที่ การตั้งค่า → บัญชี Apple → iCloud → จัดการพื้นที่จัดเก็บ โดยเลือกข้อมูลของแอปนี้
  • นอกจากนี้ยังลบข้อมูลแต่ละรายการ เช่น สมาชิกหรือรายการต่างๆ ได้เองในโหมดผู้ปกครองของแอป

7. การเปลี่ยนแปลงนโยบาย

นโยบายความเป็นส่วนตัวนี้อาจมีการแก้ไขตามการเปลี่ยนแปลงของกฎหมายหรือฟีเจอร์ของแอป หากมีการเปลี่ยนแปลงที่สำคัญจะแจ้งให้ทราบผ่านหน้านี้ และนโยบายฉบับแก้ไขจะมีผลตั้งแต่เวลาที่เผยแพร่

8. ช่องทางติดต่อ

หากมีคำถามหรือคำขอเกี่ยวกับการจัดการข้อมูลส่วนบุคคล โปรดติดต่อ
