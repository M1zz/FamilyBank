ซุกซุก ค่าขนม

แอปค่าขนมของครอบครัวที่ช่วยให้ลูกมีนิสัยการเงินที่ดีเติบโตขึ้นทุกวัน

หน้าแรก ช่วยเหลือและติดต่อ นโยบายความเป็นส่วนตัว

🐣 ซุกซุก ค่าขนม คืออะไร

ซุกซุก ค่าขนม คือแอป iOS ที่สอนเด็กๆ เรื่องการเงินและเศรษฐกิจผ่านสกุลเงินของครอบครัวเอง พ่อแม่รับบทเป็นธนาคารกลางที่ออกค่าขนมให้ ส่วนลูกได้ลองจ่ายเงิน ออมเงินเพื่อรับดอกเบี้ย และลงทุนในกองทุนจำลอง ได้เรียนรู้หลักเศรษฐศาสตร์จากการลงมือทำจริง

ข้อมูลทั้งหมดจัดเก็บไว้ในอุปกรณ์และบัญชี iCloud ของคุณเท่านั้น ไม่ต้องสมัครสมาชิก และข้อมูลที่ครอบครัวกรอกจะไม่ถูกส่งไปยังผู้พัฒนา

✨ ฟีเจอร์หลัก

  • สกุลเงินของบ้านเรา — ตั้งชื่อเงินได้เอง เช่น ถั่ว ดาว เหรียญ
  • ให้และหักค่าขนม — จัดการในโหมดผู้ปกครองที่ล็อกด้วย PIN
  • จ่ายเงิน — ลูกจ่ายค่าขนม เวลาเล่นเกม และอื่นๆ ได้เอง รองรับการจ่ายด้วยบาร์โค้ด
  • ดอกเบี้ยเงินออม — บัญชีออมทรัพย์ได้รับดอกเบี้ยทบต้นอัตโนมัติทุกสัปดาห์
  • ลองลงทุน — กองทุนจำลองแบบมั่นคง 🐢 · สมดุล 🐰 · กล้าเสี่ยง 🚀
  • ประวัติรายการ — ย้อนดูการเคลื่อนไหวของเงินทุกรายการแยกตามวัน
  • ความรู้เศรษฐกิจ — คู่มือเรื่องเงิน การออม ดอกเบี้ยทบต้น การลงทุน ค่าเสียโอกาส และอื่นๆ
